# SOP-002 Mandatory Fields and Missing Information Follow-up

Purpose: ensure no report is saved with missing mandatory data.

Mandatory for all reports: product name, batch/lot number, date received, reporter type, intake channel and description.
Additional mandatory fields for a Suspected Adverse Event: event description and event onset date. The onset date cannot be later than the date received.

If a mandatory field is missing the system shows an explicit error naming the field. Operators must not guess values. Where the reporter cannot supply a lot number, request the information again through the original channel and note the follow-up request in the case. Reports remain unsaved until all mandatory fields pass validation.
